# TwiT 1.0 — DanikDeJesus

Primera versión numerada 1.0 para pruebas comunitarias. Incluye Twitch y Kick, seguidos, preview de directo, multivista, selector de calidad y audio, biblioteca de VOD con barra de tiempo, chats de lectura y navegación con mando.

Icono transparente para Fire TV y nuevo banner de proporciones uniformes, fondo verde petróleo opaco y tipografía original TwiT sin borde añadido. Firma DanikDeJesus incorporada en el código y metadatos, sin alterar la lógica de reproducción.

Probada en Fire TV HD con Fire OS 7. Las integraciones de plataforma siguen siendo experimentales. Consulta las limitaciones del README antes de instalar.
